  <action>
    Add to `backend/app/schemas/deal.py`:
    - `PriceTrendPoint(date: str, avg_modal_price: float)` — date as ISO string.
    - `DisputeSummary(id: int, deal_id: int, raised_by: int, reason: str, status: str, created_at: datetime)`
      with `from_attributes=True`.
    - `AdminDashboardResponse`:
      `total_lots: int`, `open_lots: int`,
      `total_demands: int`, `open_demands: int`,
      `total_deals: int`, `open_disputes_count: int`,
      `price_trend_summary: list[PriceTrendPoint]`,
      `dispute_queue: list[DisputeSummary]`

    Create `backend/app/api/admin.py`:

    **GET /api/admin/dashboard** dep: `CurrentUser` + `require_role("admin")`, `db`:

    Execute these queries:
    - `total_lots = SELECT COUNT(*) FROM lots`
    - `open_lots = SELECT COUNT(*) FROM lots WHERE status='open'`
    - `total_demands = SELECT COUNT(*) FROM demands`
    - `open_demands = SELECT COUNT(*) FROM demands WHERE status='open'`
    - `total_deals = SELECT COUNT(*) FROM deals`
    - `open_disputes_count = SELECT COUNT(*) FROM disputes WHERE status='open'`

    Price trend summary (last 30 days):
    - `SELECT DATE(date) as day, AVG(modal_price) as avg_price FROM price_cache WHERE date >= today-30 GROUP BY day ORDER BY day ASC`
    - Returns `list[PriceTrendPoint]`

    Dispute queue:
    - `SELECT * FROM disputes WHERE status='open' ORDER BY created_at DESC`
    - Returns `list[DisputeSummary]`

    Use SQLAlchemy `func.count()`, `func.avg()`, `func.date()` / column-level `.cast(Date)`.
    For the date grouping on SQLite (used in tests), use `func.date(PriceCache.date)`;
    on PostgreSQL the same expression works.

    In `app/main.py`, include `admin_router`.
  </action>

    - Import smoke: `python -c "from app.api.admin import router; print('OK')"`.
