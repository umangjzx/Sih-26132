    1. Create `backend/app/schemas/deal.py` (Pydantic v2):
       - Import `LotSummary`, `DemandSummary`, `CounterpartySummary` from `app.schemas.match`
         and `DealResponse` from `app.schemas.offer`.
       - `DealDetailResponse` — all fields from `DealResponse` plus:
         `lot: LotSummary`, `demand: DemandSummary`, `counterparty: CounterpartySummary | None`
         (assembled manually, not from_attributes for the nested fields)
       - `DisputeCreate(reason: str)` — validator: `reason.strip()` not empty.
       - `DisputeResponse(id, deal_id, raised_by, reason, status, created_at)` with `from_attributes=True`.
       - `HistoryResponse(lots: list[LotResponse], demands: list[DemandResponse], deals: list[DealDetailResponse])`
         (import `LotResponse` from `app.schemas.lot`, `DemandResponse` from `app.schemas.demand`).

    2. Create `backend/app/api/deals.py`:
       Define the pipeline order as a module-level constant:
       ```python
       PIPELINE_STAGES = [
           "matched", "offer_accepted", "logistics_arranged",
           "delivered", "paid", "closed"
       ]
       ```

       **Helper `_load_deal_with_access(deal_id, user_id, db) -> tuple[Deal, Match, Lot, Demand]`:**
       - Joins Deal → Match → Lot, Deal → Match → Demand.
       - 404 if not found.
       - Verifies caller is farmer of lot, buyer of demand, or admin. 403 otherwise.
       - Returns (deal, match, lot, demand).

       **GET /api/deals/mine** dep: `CurrentUser`, `db`:
       - Farmer: `SELECT deals JOIN matches JOIN lots WHERE lots.farmer_id = me ORDER BY created_at DESC`
       - Buyer: `SELECT deals JOIN matches JOIN demands WHERE demands.buyer_id = me ORDER BY created_at DESC`
       - Admin: all deals
       - For each deal, load the match+lot+demand+counterparty and assemble `DealDetailResponse`.
       - Return `list[DealDetailResponse]`.

       **GET /api/deals/{deal_id}** dep: `CurrentUser`, `db`:
       - Use `_load_deal_with_access`. Assemble and return `DealDetailResponse`.

       **PATCH /api/deals/{deal_id}/advance** dep: `CurrentUser`, `db`:
       - Use `_load_deal_with_access`.
       - Find current index in `PIPELINE_STAGES`. If not found or at last stage ("closed") → 400.
       - Set `deal.pipeline_status = PIPELINE_STAGES[current_index + 1]`.
       - If new status == "paid": set `deal.payment_status = "paid"`.
       - Commit. Return `DealDetailResponse`.

    3. In `backend/app/main.py`, import and include `deals_router`.
  </action>
