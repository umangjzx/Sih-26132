  <action>
    1. Create `backend/app/schemas/auth.py` (Pydantic v2):
       - `OtpRequestBody(phone: str, name: str, role: Literal["farmer","buyer","admin"] = "farmer")`
       - `OtpVerifyBody(phone: str, code: str)`
       - `RefreshBody(refresh_token: str)`
       - `TokenResponse(access_token: str, refresh_token: str, token_type: str = "bearer")`
       - `UserResponse(id: int, phone: str, name: str, role: str, district: str, taluka: str, kyc_status: str, is_active: bool)` with `model_config = ConfigDict(from_attributes=True)`
       - `AuthResponse(access_token: str, refresh_token: str, token_type: str, user: UserResponse)`
    2. Create `backend/app/api/auth.py`:
       - `router = APIRouter(prefix="/api/auth", tags=["auth"])`
       - `POST /otp/request` body: `OtpRequestBody`. Logic:
         a. Look up user by `phone`. If not found, create with `role`, `name`, `district=""`, `taluka=""`.
         b. `otp = generate_otp()`. Set `user.otp_code = otp`, `user.otp_expires_at = now + otp_ttl_seconds`.
         c. Commit.
         d. `logger.info("[AgriLink OTP] Phone %s → Code: %s (expires %d min)", phone, otp, settings.otp_ttl_seconds // 60)`. Return `{"detail": "OTP sent"}`.
       - `POST /otp/verify` body: `OtpVerifyBody`. Logic:
         a. Look up user by phone → 401 if not found.
         b. Check `user.otp_code` is not None, `user.otp_expires_at > now`, `secrets.compare_digest(code, otp_code)` → 401 "Invalid or expired OTP" if any fail.
         c. Clear `otp_code` and `otp_expires_at`. Commit.
         d. Return `AuthResponse(access_token=create_access_token(str(user.id), {"role": user.role}), refresh_token=create_refresh_token(str(user.id)), token_type="bearer", user=UserResponse.model_validate(user))`.
       - `POST /refresh` body: `RefreshBody`. Logic:
         a. `decode_token(refresh_token)` → 401 on JWTError.
         b. Check `payload["type"] == "refresh"` → 401 if not.
         c. Fetch user by `payload["sub"]` → 401 if not found or `not user.is_active`.
         d. Return `TokenResponse(access_token=create_access_token(...), refresh_token=create_refresh_token(...))`.
       - `GET /me` with `CurrentUser` dep → return `UserResponse.model_validate(current_user)`.
    3. In `backend/app/main.py`:
       - Import and include `auth_router` from `app.api.auth`.
       - Widen CORS: `allow_methods=["GET", "POST", "PUT", "PATCH", "DELETE"]`, `allow_credentials=True`.
       - Keep the Phase 2 comment.
  </action>
