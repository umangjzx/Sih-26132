    1. Create `backend/app/services/matching.py`:

       ```python
       # Scoring constants
       QUANTITY_MAX = 30
       PRICE_MAX = 40
       DISTANCE_MAX = 30
       MIN_SCORE = 30  # pairs below this are discarded

       def _quantity_score(lot_qty: float, demand_qty: float) -> float:
           """0–30 pts. Ratio of the smaller to the larger quantity."""
           if lot_qty <= 0 or demand_qty <= 0:
               return 0.0
           ratio = min(lot_qty, demand_qty) / max(lot_qty, demand_qty)
           return round(ratio * QUANTITY_MAX, 2)

       def _price_score(expected: float, band_min: float, band_max: float) -> float:
           """0–40 pts.
           - expected fully within [band_min, band_max] → 40
           - expected outside the band → 0
           - band_min == band_max (point price) → 40 if match, 0 otherwise
           """
           if band_min <= expected <= band_max:
               return float(PRICE_MAX)
           # Partial credit: how far is expected from the nearest band edge?
           band_width = band_max - band_min
           if band_width <= 0:
               return 0.0
           gap = max(0.0, band_min - expected, expected - band_max)
           fraction = max(0.0, 1.0 - gap / band_width)
           return round(fraction * PRICE_MAX, 2)

       def _distance_score(lot_location: str, demand_district: str) -> float:
           """0–30 pts based on haversine distance between district centroids.
           Unknown centroid → neutral 15 pts.
           """
           dist = district_distance_km(lot_location, demand_district)
           if dist is None:
               return 15.0
           if dist <= 50:
               return 30.0
           if dist <= 150:
               return 20.0
           if dist <= 300:
               return 10.0
           return 0.0

       def score_pair(lot: Lot, demand: Demand) -> tuple[float, str]:
           """Returns (total_score, score_detail_json).
           score_detail_json is a JSON string for storage in Match.score_detail.
           Caller must check crop match before calling.
           """
           q = _quantity_score(lot.quantity_kg, demand.quantity_kg)
           p = _price_score(lot.expected_price, demand.price_band_min, demand.price_band_max)
           d = _distance_score(lot.location, demand.district if hasattr(demand, 'district') else "")
           # demand.district is not on the Demand model; look it up from the buyer user
           # Actually: demand has no district column — use buyer's district via a separate lookup.
           # The caller (run_matching) passes buyer_district explicitly; see run_matching below.
           total = round(q + p + d, 2)
           detail = json.dumps({
               "quantity": q,
               "price": p,
               "distance": d,
               "total": total,
               "max": QUANTITY_MAX + PRICE_MAX + DISTANCE_MAX,
           })
           return total, detail
       ```

       **Important implementation note on demand.district**: The `Demand` model has no `district`
       column. Distance scoring uses the buyer's district from the `User` table.
       `run_matching()` must JOIN users to get this. Design `score_pair` to accept
       `buyer_district: str` as an explicit parameter rather than accessing demand attributes.

       Full `run_matching(db: Session) -> int` implementation:
       - Query all open lots: `SELECT lots WHERE status='open'`
       - Query all open demands: `SELECT demands JOIN users ON buyer_id=users.id WHERE demands.status='open'` (also pull `users.district` as `buyer_district`)
       - For each (lot, demand) pair where `lot.crop == demand.crop`:
         - Call `score_pair(lot, demand, buyer_district)`
         - If `total < MIN_SCORE`: skip (do not insert)
         - Else: upsert into `matches` — check if a `Match` row exists for `(lot_id, demand_id)`. If yes and `status in ("proposed", "offered")`: update `score` and `score_detail`. If not exists: insert with `status="proposed"`.
       - Commit once after all upserts.
       - Return count of upserted rows.

       Ensure `score_pair` signature is:
       `def score_pair(lot_qty: float, lot_expected_price: float, lot_location: str, demand_qty: float, demand_band_min: float, demand_band_max: float, buyer_district: str) -> tuple[float, str]:`
       (pure function — no ORM objects, fully testable without a DB)
