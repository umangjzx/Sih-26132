         `model_config = ConfigDict(from_attributes=True)`

    2. Create `backend/app/api/offers.py`:
       - `router = APIRouter(tags=["offers"])`  (no single prefix — two route groups)

       **POST /api/matches/{match_id}/offers** dep: `CurrentUser`, `db`:
         a. Load `Match` by id → 404 if missing.
         b. Load the `Lot` (lot_id) and `Demand` (demand_id) of the match.
         c. Verify `current_user.id == lot.farmer_id or current_user.id == demand.buyer_id` → 403.
         d. Validate `match.status in ("proposed", "offered")` → 400 "Match is not open for offers" otherwise.
         e. If any existing `Offer` for this match has `status == "pending"`, set it to `"countered"` and add to session.
         f. Create new `Offer(match_id=match_id, from_user_id=current_user.id, price=body.price, quantity=body.quantity, message=body.message)`.
         g. Set `match.status = "offered"`.
         h. Commit. Return `OfferResponse.model_validate(new_offer)`.

       **GET /api/matches/{match_id}/offers** dep: `CurrentUser`, `db`:
         a. Load match → 404 if missing.
         b. Verify current user is farmer of the lot or buyer of the demand → 403.
         c. Return `list[OfferResponse]` for all offers on this match, ordered `created_at asc`.

       **POST /api/offers/{offer_id}/accept** dep: `CurrentUser`, `db`:
         a. Load `Offer` by id → 404 if missing.
         b. Verify `offer.status == "pending"` → 400 "Offer is not pending".
         c. Load match, lot, demand. Verify current user is the *other* party (not the one who made the offer: `offer.from_user_id != current_user.id`) → 403. Also verify ownership of lot or demand.
         d. Set `offer.status = "accepted"`.
         e. Set all other `pending` offers on the same match to `"declined"`.
         f. Set `match.status = "accepted"`.
         g. Create `Deal(match_id=match.id, agreed_price=offer.price, agreed_quantity=offer.quantity)` (defaults: `logistics_mode="self_pickup"`, `payment_status="pending"`, `pipeline_status="matched"`).
         h. Commit. Return `DealResponse.model_validate(new_deal)`.

       **POST /api/offers/{offer_id}/decline** dep: `CurrentUser`, `db`:
         a. Load `Offer` → 404 if missing.
         b. Verify `offer.status == "pending"` → 400.
         c. Verify current user is the other party (not the maker) → 403.
         d. Set `offer.status = "declined"`.
         e. Count remaining `pending` offers on the match. If zero, set `match.status = "proposed"`.
         f. Commit. Return `{"detail": "Offer declined"}`.

    3. In `backend/app/main.py`, import and include `offers_router`.
  </action>
